# ATELIER HUE — 공기에 남은 결

가상의 조향 공방 **아틀리에 휴**의 브랜드 웹사이트입니다. 디자인 시안 이미지를 바탕으로, AI 코딩 도구(Claude Code)와 함께 만든 콘셉트 작업입니다.

> 실제 브랜드가 아니며, 상품·가격·연락처·소식은 모두 예시입니다.

## 콘셉트

향은 보이지 않지만 공기에 결을 남깁니다. 그 결을 **스크롤을 따라 흩날리는 천**으로 표현했습니다.

- 무드: 옅은 회색 여백, 흑백 인물 사진, 따뜻한 향수병 색감의 대비
- 서체: Pretendard의 가는 굵기를 크게 사용
- 모션: 안내·강조·피드백의 이유가 있는 곳에만 사용

## 페이지 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 홈: 히어로, 향수 컬렉션, 소식, 찾아오시는 길 |
| `about.html` | 브랜드 스토리, 만드는 방식 |
| `collection.html` | 향수 3종 목록, 향 고르는 법 |
| `product.html?p=citrus` · `wood` · `pepper` | 향수 상세: 스펙, 노트 구조, 이야기 |
| `class.html` | 조향 클래스 소개, 진행 순서, 예약 양식, FAQ |
| `visit.html` | 약도, 오시는 방법, 문의 |
| `news.html` · `news-detail.html?n=1` | 소식 목록과 상세 |

## 주요 인터랙션

| 효과 | 설명 | 구현 |
|---|---|---|
| 흩날리는 천 | 가는 선을 비틀어 겹친 리본. 스크롤 위치에 따라 접힘이 이동하고, 속도에 따라 출렁임 | Canvas 2D (`js/silk.js`) |
| 프리로더 | 홈 첫 진입 시 0→100 카운터 | GSAP |
| 마스크 텍스트 리빌 | 제목이 틀 안에서 아래에서 올라옴 | GSAP ScrollTrigger |
| 히어로 패럴랙스 | 사진과 제목이 다른 속도로 이동 | ScrollTrigger scrub |
| 단어별 하이라이트 | 읽는 속도에 맞춰 문장이 진해짐 (`about.html`) | ScrollTrigger scrub |
| 속도 기울기 | 스크롤 속도에 따라 향수 카드가 살짝 기울어짐 | ScrollTrigger velocity |
| 마그네틱 버튼 | "클래스 예약"이 커서를 따라 끌려옴 (마우스 기기) | GSAP quickTo |
| 페이지 전환 | 어두운 막이 덮었다가 걷힘 | GSAP |

## 반응형과 접근성

- 모바일 퍼스트로 작성. 360px 폭에서 가로 스크롤이 없는 것을 확인했습니다.
- `prefers-reduced-motion` 설정에서는 등장 연출을 끄고 천을 고정하도록 작성했습니다.
- 시맨틱 태그, `focus-visible` 스타일, 키보드로 열리는 서브 메뉴를 적용했습니다.
- 마우스 전용 효과는 터치 기기에서 적용하지 않습니다.

## 사용 기술

- HTML, CSS, JavaScript (빌드 도구 없음)
- [GSAP](https://gsap.com/) + ScrollTrigger (`js/`에 포함)
- [Pretendard](https://github.com/orioncactus/pretendard) (CDN)

## 폴더 구조

```
.
├── *.html          페이지
├── css/
│   ├── style.css   홈과 공통 스타일
│   └── sub.css     서브 페이지와 공통 컴포넌트
├── js/
│   ├── layout.js   공통 헤더·푸터·서브 메뉴
│   ├── data.js     향수·소식 데이터 (내용 수정은 여기서)
│   ├── pages.js    데이터로 상세·목록 화면 생성
│   ├── silk.js     흩날리는 천
│   └── main.js     인터랙션
└── img/            사진
```

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 서체를 불러오려면 인터넷 연결이 필요합니다.

로컬 서버로 확인하려면 이 폴더에서 실행합니다.

```bash
python3 -m http.server 5180
```

그다음 브라우저에서 `http://localhost:5180`에 접속합니다.
